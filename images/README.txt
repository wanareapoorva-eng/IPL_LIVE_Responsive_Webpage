Put team logo images in this folder with these exact names:
mi.png csk.png rcb.png kkr.png dc.png srh.png rr.png gt.png pbks.png lsg.png

Download them from each team's official website or iplt20.com (right click -> Save image as).
If a file is missing, the website automatically shows a colored circle with the team name, so nothing breaks.
If your images are .jpg or .webp, change the extension in script.js (the "img" field of each team).
